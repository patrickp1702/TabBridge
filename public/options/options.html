    Profiles

      A profile is the set of tools an agent may see and call. Connector scripts and page access each point at one profile.

      Select a profile.

      Expose tools via Web MCP
      Connects this extension to the local bridge server so external MCP clients (Claude Code, Claude Desktop…) can call the tools. Tool scripts never leave the browser — the server only relays calls.
      Disabled

      Connector scripts (external agents)
      Pick a profile, download, run the script once in a terminal — it prints the config to paste into your agent (Claude Code, Claude Desktop, Cursor, …). Each download is its own connector: it exposes only that profile's tools. Validity is decided here, not by the file: when a connector expires or is deactivated the same script is refused, and Extend makes it work again without a new download. Connectors stay listed until you Delete them.
       

      ConnectorsDeactivate = refused immediately · Extend / Reactivate = valid again for N days · Delete = forgotten for good · 🔒 ToolBridge = this script may create/edit tools for 2 h
      Page access (in-page agent)
      Only pages at these origins receive tools, and only the chosen profile's tools. Every other site gets nothing — tool calls from anywhere else are refused. The 🔒 ToolBridge switch on a row lets the in-page agent at that origin create/edit tools for 2 hours (off by default).
       

      Allow plain http:// page origins
      Off (default): grants for http:// origins are refused and existing ones are ignored. localhost is always allowed.
      ⚠ Warning: pages served over plain HTTP are not protected in transit. Anyone on the same network (public Wi-Fi, a compromised router, a proxy) can inject script into such a page and then call every tool its profile exposes — and ToolBridge, if switched on for that origin. Grant http origins only on networks you trust, with the smallest profile that works.
      Recent agent activity
      Every tool call made by a connector or a granted page (last 500). Tools marked Require confirmation in Domains & Tools show an approval window before running.
